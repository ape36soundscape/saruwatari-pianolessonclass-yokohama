■ 他の端末で編集を続ける方法
1. GitHub に同じアカウントでログインします。
2. リポジトリを開きます。
   https://github.com/ape36soundscape/saruwatari-pianolessonclass-yokohama
3. Codex または GitHub 上で内容を編集します。
4. main ブランチへ保存（コミット）すると、GitHub Pages が自動で再公開します。
5. 数分後、公開URLをスマートフォンなどで再読み込みして確認します。

■ 注意事項
・Firebase URLではなく、GitHub Pages URLを案内・QRコードに使用してください。
・GitHubリポジトリが公開設定の場合、ソースコード自体も閲覧できます。
・公開サイトに反映されない場合は、ブラウザを再読み込みするか、URLの末尾に ?v=日付 などを付けて開くと確認しやすくなります。
